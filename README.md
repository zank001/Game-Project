# 💗 รักแรกผลิบาน · Blooming Hearts

เกมจีบหนุ่มแนว **Boys' Love Visual Novel** (นิยายภาพซีรีส์วาย) เล่นบนเว็บได้ทันที
ไม่ต้องติดตั้งอะไร ไม่ต้องต่อเน็ต — เปิดไฟล์เดียวก็เล่นได้เลย

> คุณคือนักศึกษาปี 1 ผู้เพิ่งก้าวเข้าสู่รั้วมหาวิทยาลัยบูรพาลัย
> และได้พบกับหนุ่มๆ สามคนที่มีเสน่ห์ต่างกันไป... หัวใจของคุณจะเลือกใคร?

## ▶️ วิธีเล่น

เปิดไฟล์ `index.html` ด้วยเว็บเบราว์เซอร์ใดก็ได้ (Chrome, Safari, Firefox, Edge)

```bash
# หรือรันเป็นเซิร์ฟเวอร์เล็กๆ (ถ้าต้องการ)
python3 -m http.server 8000
# แล้วเปิด http://localhost:8000
```

- คลิก/แตะหน้าจอ หรือกด `Space` / `Enter` เพื่อเดินเรื่อง
- เมื่อมี **ตัวเลือก** ให้เลือกคำตอบ — แต่ละคำตอบมีผลต่อ **คะแนนหัวใจ ♥** ของหนุ่มแต่ละคน
- คะแนนหัวใจกำหนดตอนจบ: **สมหวัง / ค่อยเป็นค่อยไป / พลาดโอกาส**
- ปุ่มลัด: `A` = Auto, `L` = Log ย้อนบทสนทนา, `Esc` = เมนู

## 💘 หนุ่มๆ ที่จีบได้

| ตัวละคร | บทบาท | สไตล์ |
|--------|--------|-------|
| 🔵 **ภาคิน** | รุ่นพี่ปี 3 · ประธานชมรมถ่ายภาพ | สุขุม เย็นชา แต่อ่อนโยนข้างใน |
| 🟠 **ตะวัน** | เพื่อนร่วมรุ่น · นักฟุตบอล | สดใส พลังล้น เพื่อนซี้จอมจีบ |
| 🟣 **นิล** | รุ่นพี่ปี 2 · คณะศิลปกรรม | เงียบขรึม ลึกลับ โรแมนติกแบบกวี |

**3 เส้นทางรัก × 3 ตอนจบ = 9 ตอนจบให้ตามเก็บ!**

## ✨ ฟีเจอร์

- 🎨 **ตัวละครและฉากวาดด้วย SVG ทั้งหมด** — ไม่มีไฟล์ภาพภายนอก เล่นออฟไลน์ได้ 100%
- 💬 ระบบบทสนทนาแบบ typewriter พร้อมสีหน้าตัวละครหลายแบบ
- 💗 ระบบคะแนนหัวใจ (affection) ที่ส่งผลต่อเนื้อเรื่องและตอนจบจริง
- 💾 บันทึกเกม: ออโต้เซฟ + เซฟด้วยตนเอง 4 ช่อง (เก็บใน `localStorage`)
- 🖼️ แกลเลอรีตัวละคร + สมุดสะสมตอนจบที่ปลดล็อก
- ⚙️ ปรับความเร็วข้อความ, Auto, Skip, Log ย้อนบทสนทนา
- 📱 รองรับทั้งจอคอมและมือถือ (responsive)

## 🗂️ โครงสร้างโปรเจกต์

```
index.html            หน้าเกมและโครงสร้างหน้าจอทั้งหมด
css/style.css         ธีมและ UI ทั้งหมด
js/art.js             เครื่องกำเนิดภาพตัวละคร SVG (ตามอารมณ์/สีหน้า)
js/backgrounds.js     ฉากหลัง SVG แต่ละสถานที่
js/characters.js      ข้อมูลตัวละคร (ชื่อ สี บทบาท)
js/engine.js          เอนจินเกม: ฉาก, ตัวเลือก, คะแนนหัวใจ, เซฟ/โหลด
js/story.js           เนื้อเรื่องทั้งหมด (common route + 3 เส้นทางรัก)
```

## 🛠️ อยากต่อยอด / เพิ่มเนื้อเรื่อง?

เนื้อเรื่องทั้งหมดเป็นข้อมูลใน `js/story.js` โครงสร้างแต่ละฉาก:

```js
{
  id: 'phakin_5',                    // รหัสฉาก (ไม่ซ้ำ)
  bg: 'photo_studio',                // คีย์ฉากหลัง (ดู backgrounds.js)
  who: 'phakin',                     // ผู้พูด: phakin/tawan/nil/fern/player/narrator
  sprites: [{ pos:'center', char:'phakin', expr:'blush' }],
  text: 'บทพูด...',                   // ใช้ {{PLAYER}} แทนชื่อผู้เล่น
  choices: [                          // (ถ้ามี) ตัวเลือก
    { text:'คำตอบ', p:2, next:'phakin_6' }  // p/t/n = คะแนนหัวใจ phakin/tawan/nil
  ],
  next: 'phakin_6'                    // ฉากถัดไป (ถ้าไม่มี choices)
}
```

เพิ่มฉาก เพิ่มตัวเลือก หรือแก้บทได้อิสระ — ไม่ต้อง build ใหม่
