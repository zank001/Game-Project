# 🏐 วอลเลย์คลับ สตอรี่ · Volley Club Story

เกม **จำลองบริหารสโมสรวอลเลย์บอล** สไตล์เกมค่ายญี่ปุ่นแนว management sim
กราฟิกพิกเซล เล่นบนเว็บได้ทันที ไม่ต้องติดตั้ง ไม่ต้องต่อเน็ต — เปิดไฟล์เดียวก็เล่นได้เลย

> คุณคือผู้จัดการสโมสรวอลเลย์บอลเล็กๆ ในชุมชน
> ฝึกซ้อมนักกีฬา สร้างสิ่งอำนวยความสะดวก หาสปอนเซอร์ เก็บแฟนคลับ
> แล้วพาทีมไต่จากถ้วยชุมชน... สู่แชมป์สโมสรโลก! 🌏

## ▶️ วิธีเล่น

**ง่ายที่สุด:** ดาวน์โหลดไฟล์เดียว `standalone.html` แล้วดับเบิลคลิกเปิดได้เลย
(รวมทุกอย่างไว้ในไฟล์เดียว เล่นออฟไลน์ 100%)

**หรือ** เปิดไฟล์ `index.html` (เวอร์ชันแยกไฟล์สำหรับพัฒนาต่อ) ด้วยเบราว์เซอร์ใดก็ได้

```bash
# หรือรันเป็นเซิร์ฟเวอร์เล็กๆ (ถ้าต้องการ)
python3 -m http.server 8000
# แล้วเปิด http://localhost:8000
```

> 💡 `standalone.html` สร้างจากไฟล์ต้นฉบับด้วย `node build.js` (รวม css + js ทั้งหมดเป็นไฟล์เดียว)

## 🎮 เกมเพลย์

**ทุกสัปดาห์เลือกทำ 1 อย่าง** แล้วเวลาจะเดินไปเรื่อยๆ:

| การกระทำ | ผล |
|----------|-----|
| 🏐 **ฝึกซ้อม** | เพิ่มสเตตัส (เสิร์ฟ/ตบ/บล็อก/รับ/เซ็ต/อึด) แลกกับความสดชื่น |
| 😴 **พักผ่อน** | ฟื้นความสดชื่นและกำลังใจ — ซ้อมตอนเหนื่อยผลจะแย่ลง! |
| 🤝 **นัดอุ่นเครื่อง** | หาเงิน ประสบการณ์ และแฟนคลับ ดูแมตช์สดๆ ทีละแรลลี่ |
| 🕵️ **แมวมอง** | เสาะหานักกีฬาใหม่มาเซ็นสัญญาเสริมทีม (สูงสุด 10 คน) |

**ระบบหลัก**

- 👥 **นักกีฬา 5 ตำแหน่ง** — เซ็ตเตอร์ / ตบหัวเสา / บล็อกกลาง / ตบตรงข้าม / ลิเบอโร่
  แต่ละคนมีเลเวล, EXP, พรสวรรค์ (★1–5) และโตตามตำแหน่งของตัวเอง
- 🏟️ **สิ่งอำนวยความสะดวก 6 อย่าง** — ห้องเวท, เครื่องยิงบอล, ห้องวิเคราะห์เกม, ห้องฟื้นฟู, โรงอาหาร, ร้านของที่ระลึก (อัปเกรดได้ 3 ระดับ)
- 🤝 **สปอนเซอร์ 6 ราย** — ปลดล็อกตามยอดแฟนคลับ จ่ายเงินให้ทุกสัปดาห์
- 💛 **แฟนคลับ & กำลังใจ & ความเข้าขา** — ทุกอย่างส่งผลถึงฟอร์มในสนามจริง
- 🎲 **อีเวนต์สุ่มรายสัปดาห์** — คลิปไวรัล, หมูกระทะเชื่อมทีม, หลังคายิมรั่ว ฯลฯ

**เส้นทางสู่แชมป์โลก** — ชนะรายการเล็กเพื่อปลดล็อกรายการใหญ่:

```
🥉 ถ้วยชุมชนคัพ (เดือน 3) → 🥈 ชิงแชมป์จังหวัด (เดือน 6) → 🥇 ชิงแชมป์ภูมิภาค (เดือน 9)
→ 🏆 ไทยแลนด์ซูเปอร์ลีก (เดือน 12) → 🌏 เวิลด์คลับแชมเปียนชิพ (เดือน 1 ตั้งแต่ปี 2)
```

**การแข่งขัน** จำลองทีละแรลลี่จากสเตตัสจริงของผู้เล่นทั้ง 12 คนในสนาม
(เสิร์ฟ → รับ → เซ็ต → ตบ → บล็อก/รับตบ) พร้อมแอนิเมชันพิกเซล เร่งความเร็ว x2/x4 หรือข้ามไปดูผลได้

## ✨ ฟีเจอร์เทคนิค

- 🎨 กราฟิกพิกเซลวาดสดด้วย canvas ทั้งหมด — ไม่มีไฟล์ภาพภายนอก
- 🔊 เสียงเอฟเฟกต์สังเคราะห์ด้วย Web Audio — ไม่มีไฟล์เสียง
- 💾 เซฟอัตโนมัติทุกสัปดาห์ลง `localStorage` (มี fallback ในหน่วยความจำเมื่อถูกบล็อก)
- 📱 รองรับทั้งจอคอมและมือถือ (responsive + ปุ่มใหญ่กดง่าย)
- 🇹🇭 ภาษาไทยทั้งเกม

## 🗂️ โครงสร้างโปรเจกต์

```
index.html        โครงหน้าเว็บ (เวอร์ชันแยกไฟล์)
standalone.html   เวอร์ชันรวมไฟล์เดียว เล่นออฟไลน์ (สร้างด้วย node build.js)
build.js          สคริปต์รวมไฟล์
css/style.css     สไตล์ UI ทั้งหมด
js/data.js        ข้อมูลเกม: ตำแหน่ง การฝึก สิ่งปลูกสร้าง สปอนเซอร์ ทัวร์นาเมนต์ คู่แข่ง อีเวนต์
js/sprites.js     วาดกราฟิกพิกเซล (สนาม นักกีฬา ลูกบอล)
js/sound.js       เสียงสังเคราะห์ Web Audio
js/game.js        สถานะเกม + กฎทั้งหมด (ปฏิทิน เศรษฐกิจ เลเวล ทัวร์นาเมนต์ เซฟ/โหลด)
js/match.js       เอนจินจำลองแมตช์ทีละแรลลี่ + แอนิเมชัน
js/ui.js          หน้าจอ เมนู โมดัล
```
