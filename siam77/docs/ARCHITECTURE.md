# สถาปัตยกรรมโค้ด Siam77

เกมเขียนด้วย HTML/CSS/JavaScript ล้วน ไม่มี dependency และไม่ใช้ ES modules (เพื่อให้เปิดจาก `file://` และรวมเป็นไฟล์เดียวได้)
ทุกไฟล์ผูกเข้ากับ namespace เดียวคือ `S77` ลำดับการโหลดกำหนดใน `index.html`

```
util → data_geo → data_provinces → data_game → worldgen → sprites → render → systems → game → input → ui → main
```

## 1. โลก (worldgen.js)

`new S77.World(seed).generate(progress)` สร้างโลกแบบกำหนดผลได้ — seed เดิมได้โลกเดิมเสมอ จึง **ไม่ต้องบันทึกแผนที่ลงเซฟ**
เซฟเก็บเฉพาะสิ่งที่ผู้เล่นเปลี่ยน

| ชั้นข้อมูล (typed array ขนาด W×H) | ความหมาย |
|---|---|
| `ter` | ชนิดภูมิประเทศ (`S77.T`) |
| `prov` | จังหวัด (index+1, 0 = ไม่มี) |
| `obj` | วัตถุตกแต่ง/ต้นไม้/ภูเขา (`S77.O`) — `S77.OBJ_BLOCK` บอกว่าชนแบบไหน |
| `bld` | id อาคาร+1 ที่ครอบช่องนั้น |
| `elev` | ความสูง (ใช้เลือกภูเขา/เนินเขา) |
| `zone` | ตัวเมือง (1–77) หรือหมู่บ้าน (100+id) |
| `road`, `flag` | ทิศเส้นกลางถนน, บิตประตู/ห้ามตกแต่ง |

ขั้นตอนการสร้าง: เส้นขอบประเทศ (scanline polygon fill) → แม่น้ำ/ทะเลสาบ → ระยะห่างชายฝั่ง (BFS) → เทือกเขา (ridge field บน coarse grid)
→ วางตัวเมือง 77 แห่ง (ดันให้ไม่ทับกันในภาคกลาง) → เขตจังหวัด (Voronoi + domain warp, seed เสริมเพื่อรูปร่าง)
→ ไบโอมตามภาค → ผังถนนในเมือง → ทางหลวง (A* บนกริดหยาบ 4 ทิศ + ค่าปรับการเลี้ยว) → วางอาคาร (lot ติดถนน) → หมู่บ้าน → ตกแต่ง

อาคารเป็นออบเจกต์ใน `world.buildings` (`{type, x, y, fw, fd, door, town|village, prov, variant}`) และถูกจัดดัชนีตาม chunk ขนาด 16×16

## 2. กราฟิก (sprites.js + render.js)

- **ไม่มีไฟล์ภาพ** — ทุกอย่างวาดตอนรัน
- **ไทล์** 32×16 รูปข้าวหลามตัดแบบ pixel-centre (ต่อกันไร้รอย) มีหลายแบบ และนาข้าวเปลี่ยนตามฤดู
- **Voxel/Span renderer** (`renderVox`) — นิยามโมเดล 3D ด้วยชิ้นส่วนง่ายๆ (`P.box`, `P.gable`, `P.hip`, `P.dome`, `P.lathe`, `P.sphere` …)
  แล้วเรนเดอร์เป็นภาพ isometric พร้อมแรเงาตามความชัน ขอบไฮไลต์ และเส้นขอบ — ใช้กับอาคาร แลนด์มาร์ก ต้นไม้ ภูเขา
  อยากเพิ่มอาคารใหม่ก็แค่เขียนฟังก์ชันใน `STYLES` หรือ `LM`
- **ตัวละคร** วาดจากเทมเพลตพิกเซล 16×28 ปรับสีผิว/ผม/เสื้อ/หมวก ได้ 4 เฟรมเดิน × หน้า/หลัง × ซ้าย/ขวา
- **Renderer**: วาดลงบัฟเฟอร์ความละเอียดต่ำแล้วขยายแบบ nearest-neighbour (pixel art แท้)
  - พื้น: cache เป็น chunk 16×16 (LRU) — น้ำต่ำกว่าพื้น 4px มีหน้าผาดินและฟองคลื่น
  - วัตถุ/อาคาร/ตัวละคร: depth sort ด้วย `x+y`; อาคารหลายช่องถูกหั่นเป็น "แถบ" กว้าง 16px ตามคอลัมน์ isometric เพื่อให้บังกันถูกต้อง
  - แสง: light-map แบบ multiply (ยามเช้า/เย็น/กลางคืน) + แสงไฟถนน/หน้าต่างแบบ additive; ฝน หมอก ฝุ่น
  - ข้อความภาษาไทย (ป้ายชื่อ/ตัวเลขลอย) วาดทีหลังที่ความละเอียดจอจริงให้คมชัด

## 3. ระบบจำลอง (systems.js)

ทุกระบบลงทะเบียนผ่าน `S77.registerSystem({...})` และมี hook เหล่านี้ (มีหรือไม่มีก็ได้)

```js
{ id, init(game), update(dt, game), onHour(hour, game), onDay(day, game), save(game), load(data, game) }
```

| ระบบ | หน้าที่ |
|---|---|
| `weather` | ฝนตามฤดู หมอกภาคเหนือ ฝุ่นควัน |
| `needs` | ความอิ่ม/พลังงาน/อารมณ์/สุขภาพ หมดสติ |
| `provinces` | สถานะจังหวัด ปัญหาตามฤดู ที่นั่ง ส.ส. จำลองรายวัน |
| `npcs` | สร้างประชากรแบบ lazy เมื่อผู้เล่นเข้าใกล้ ตารางชีวิต การเดิน A* |
| `quests` | เสนอ/รับ/จบภารกิจ |

ส่วนเสริมอื่นในไฟล์เดียวกัน: `S77.GameTime` (ปฏิทิน พ.ศ. แสงตามเวลา), `S77.Econ` (ราคาซื้อขาย ค่าแรง ที่พัก บ้าน),
`S77.Talk` (สร้างบทสนทนาจากภาษาถิ่น อาชีพ อากาศ ปัญหา), `S77.Travel` (ราคาและเวลาเดินทาง), `S77.findPath` (A* ระดับไทล์)

**ประชากร NPC** ถูกสร้างแบบกำหนดผลได้จาก zone id (`populate(game, zone)`) — ข้อมูลที่ต้องจำ (ความสนิท การพบกัน ภารกิจ)
อยู่ใน `game.npcMem[npcId]` เท่านั้น ทำให้ทั้งประเทศมีคนเป็นพันโดยไม่หนักหน่วยความจำ

## 4. เกมและการโต้ตอบ (game.js)

- `Game.update(dt)` → เดินผู้เล่น (ชนแบบวงกลมกับไทล์/ลำต้นไม้) → อัปเดตทุกระบบ → ประมวลชั่วโมง/วันใหม่ → กล้องตาม → หาเป้าหมายโต้ตอบ
- เป้าหมาย: NPC → ประตูอาคาร → ท่าเรือ → วัตถุ (ศาลพระภูมิ) → ภูมิประเทศ (นา ชายหาด สวนยาง สวนผลไม้)
- **การกระทำในอาคาร** อยู่ในตาราง `S77.ACTS` (key ตรงกับ `acts` ใน `S77.BUILDINGS`) — แต่ละตัวคืน `{label, sub, disabled, run}`
  เพิ่มการกระทำใหม่ = เพิ่ม key ใน `ACTS` และใส่ชื่อใน `acts` ของอาคาร
- `advanceTime(min)` ใช้กับการทำงาน นอน เดินทาง — ยิง `onHour/onDay` ของทุกระบบอย่างถูกต้อง

## 5. Event Bus

`S77.Events.on(name, fn)` / `emit(name, data)` — เหตุการณ์ที่มีอยู่แล้ว:

`newGame` `hour` `day` `enterProvince` `enterZone` `money` `repChange` `jobDone` `purchase` `sell` `useItem`
`talk` `gift` `questStart` `questDone` `travel` `sleep` `photo` `merit` `petition` `townhall` `register` `buyHouse` `provinceTick`

## 6. การบันทึก

`game.serialize()` = `{ v, savedAt, time, player, sys: {systemId: system.save()} }` เก็บผ่าน `S77.Store`
(localStorage หรือหน่วยความจำถ้าเบราว์เซอร์บล็อก) ช่อง `auto`, `1`, `2`, `3`
