# Phase 2 — เกมการเมืองเต็มรูปแบบ

Phase 1 สร้างโลกที่ "มีชีวิต" ไว้แล้ว Phase 2 จะต่อยอดเป็นเกมการเมือง (ลงสมัคร หาเสียง เลือกตั้ง ตั้งรัฐบาล ผลักดันนโยบาย)
เอกสารนี้สรุป **สิ่งที่พร้อมใช้แล้ว** และ **วิธีต่อยอดโดยไม่ต้องรื้อระบบเดิม**

> ข้อกำหนดเนื้อหา: พรรค นักการเมือง และเหตุการณ์ทั้งหมดต้องเป็นเรื่องสมมติ ไม่อ้างอิงบุคคลหรือพรรคการเมืองจริง

## ✅ ข้อมูลและ hook ที่มีแล้วใน Phase 1

| ส่วน | ที่อยู่ | ใช้ใน Phase 2 อย่างไร |
|---|---|---|
| สถานะจังหวัด `econ happiness development environment education health safety unemployment` | `game.provState[i]` | ตัวชี้วัดผลงานรัฐบาล/ผลของนโยบาย |
| ปัญหาประจำจังหวัด `issues[{id, sev}]` + ตามฤดู | `game.provState[i].issues`, `S77.ISSUES` | ประเด็นหาเสียง คะแนนตามการแก้ปัญหา |
| ที่นั่ง ส.ส. เขต (รวม 400) | `game.provState[i].seats`, `S77.TOTAL_SEATS` | แบ่งเขตเลือกตั้ง |
| โปรไฟล์การเมืองรายบุคคล `politics {econ, social, local, turnout}` | NPC ทุกคน | จำลองการตัดสินใจลงคะแนน |
| ผู้ว่าฯ ผู้ใหญ่บ้าน โต๊ะอิหม่าม | NPC อาชีพ `governor` `headman` `imam` | ผู้มีอิทธิพลท้องถิ่น/ผู้ประสานงาน |
| พรรคสมมติ 4 พรรค + แกนอุดมการณ์ | `S77.PARTIES` | พรรคคู่แข่ง/พรรคที่ผู้เล่นสังกัด |
| ความนิยมตัวอย่าง | `S77.partySupport(game, provIdx)` | แทนด้วยแบบจำลองเต็มใน Phase 2 |
| ชื่อเสียงรายจังหวัด | `player.rep[77]` | ฐานเสียงตั้งต้น |
| ทักษะ `charisma knowledge trade labor` | `player.skills` | ปราศรัย ดีเบต เจรจา บริหาร |
| ทะเบียนบ้าน | `player.regProv` (ย้ายได้ที่ศาลากลาง) | สิทธิ์ลงสมัครในเขต |
| เงินฝาก | `player.bank` | ทุนหาเสียง |
| เครือข่ายเพื่อน | `game.npcMem[id].f` | หัวคะแนนอาสา/ผู้สนับสนุน |
| อาคาร `hall` `sala` `vsala` `parliament` `govhouse` | `S77.BUILDINGS` | ที่ยื่นสมัคร เวทีปราศรัย รัฐสภา ทำเนียบ |
| กิจกรรมพลเมือง `petition` `townhall` | `S77.ACTS` | ต่อยอดเป็นการลงพื้นที่/ประชาพิจารณ์ |
| Event Bus | `S77.Events` | ดักทุกการกระทำของผู้เล่นเพื่อคิดคะแนนนิยม |
| ปฏิทิน + เทศกาล | `S77.GameTime` | กำหนดวันเลือกตั้ง ช่วงหาเสียง สมัยประชุม |

## 🧩 วิธีเพิ่มระบบใหม่ (ตัวอย่าง)

```js
// js/politics.js — โหลดหลัง systems.js และก่อน main.js
S77.registerSystem({
  id: 'politics',
  init(g) {
    g.politics = g.politics || { party: null, candidacy: null, polls: {}, electionDay: g.time.day + 90 };
    // ความนิยมเปลี่ยนตามสิ่งที่ผู้เล่นทำ
    this.off = [
      S77.Events.on('townhall', ({ prov }) => this.bump(g, prov, 0.6)),
      S77.Events.on('petition', ({ prov }) => this.bump(g, prov, 0.4)),
      S77.Events.on('questDone', (q) => this.bump(g, q.giverProv, 0.3)),
    ];
  },
  bump(g, prov, k) { const p = (g.politics.polls[prov] = g.politics.polls[prov] || 0); g.politics.polls[prov] = p + k; },
  onDay(day, g) { if (day === g.politics.electionDay) S77.UI.banner('🗳️ วันเลือกตั้ง!', 'ออกไปใช้สิทธิ์กันเถอะ'); },
  save(g) { return g.politics; },
  load(d, g) { g.politics = d; },
});
```

เพิ่มการกระทำในอาคารโดยไม่ต้องแก้ game.js:

```js
S77.ACTS.run_for_mp = { opt: (g, b, pi) => ({
  label: '🗳️ ยื่นใบสมัคร ส.ส. เขต' + S77.PROVINCES[pi].th,
  disabled: g.player.regProv !== pi,
  run: () => { /* ... */ },
}) };
S77.BUILDINGS.hall.acts.push('run_for_mp');
```

## 🗺️ แผนงานที่เสนอ

1. **พรรคและการสังกัด** — สมัครเข้าพรรค/ตั้งพรรคใหม่ (ชื่อ สี โลโก้ อุดมการณ์) ระบบสมาชิกพรรค
2. **การลงสมัคร** — คุณสมบัติจากทะเบียนบ้าน อายุ ชื่อเสียงขั้นต่ำ ค่าสมัคร · เขตเลือกตั้งย่อยภายในจังหวัดตาม `seats`
3. **หาเสียง** — ปราศรัยที่ศาลาประชาคม (มินิเกมเลือกประเด็นให้ตรงกับ `issues`) เดินเคาะประตู ติดป้าย ขอเสียงผู้ใหญ่บ้าน ดีเบตกับคู่แข่ง
4. **แบบจำลองการลงคะแนน** — ใช้ระยะห่างอุดมการณ์ NPC ↔ พรรค/ผู้สมัคร + ประเด็นที่แต่ละคนสนใจ + ชื่อเสียง + `turnout`
   แล้วขยายผลจากตัวอย่าง NPC เป็นประชากรจริงของจังหวัด (`PROVINCES[i].pop`)
5. **วันเลือกตั้งและการนับคะแนน** — แอนิเมชันบนแผนที่ (โหมด "ผลเลือกตั้ง" เพิ่มใน `UI.worldMap` ได้ทันทีเพราะมีระบบ overlay รายจังหวัดแล้ว)
6. **รัฐสภาและรัฐบาล** — รวมเสียงตั้งรัฐบาล โควตารัฐมนตรี ญัตติ/การลงมติในอาคารรัฐสภา
7. **นโยบาย** — งบประมาณจังหวัด โครงการ (ถนน โรงพยาบาล ชลประทาน ฝุ่นควัน) ที่ปรับค่าใน `provState` จริง และส่งผลต่อ `happiness` ในการเลือกตั้งครั้งถัดไป
8. **สื่อและกระแส** — ข่าวรายวันจากเหตุการณ์ใน `provinceTick` เรตติ้งผู้นำ เหตุการณ์สุ่ม (เรื่องอื้อฉาว ภัยพิบัติ)

## 🧪 ข้อควรระวัง

- โลกถูกสร้างจาก seed — id ของอาคาร หมู่บ้าน และ NPC คงที่ ใช้อ้างอิงในเซฟได้ แต่ **ถ้าแก้อัลกอริทึม worldgen ให้เพิ่ม `VERSION` ในเซฟ** และเขียน migration
- NPC ถูกสร้างเมื่อผู้เล่นเข้าใกล้เท่านั้น การคำนวณผลเลือกตั้งทั้งประเทศควรใช้ `populate()` แบบไม่ spawn หรือใช้สถิติระดับจังหวัด
