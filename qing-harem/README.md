# 🏮 ลิขิตหงส์ · วังหลังต้าชิง
### Phoenix Ascent — The Qing Inner Court

เกมกลยุทธ์ผสมนิยายภาพ แนว **ไต่เต้าวังหลังสมัยชิง** — คุณคือหญิงสาวอายุ 16 ผู้ก้าวเข้าสู่วังต้องห้ามในรัชศกเฉิงผิง
และต้องไต่จาก **ก้นบึ้งที่สุด** ขึ้นไปจนถึง **จุดสูงสุดของสตรีในแผ่นดิน** ด้วยปัญญา เสน่ห์ เล่ห์เหลี่ยม และหัวใจที่ยอมจ่ายราคา

เล่นได้ทันทีในเบราว์เซอร์ ไม่ต้องติดตั้ง ไม่ต้องต่อเน็ต — เปิดไฟล์เดียว `standalone.html` ก็เล่นได้เลย (ใช้ได้ทั้งคอมและมือถือ)

## 👑 บันไดแห่งวังหลัง

```
นางกำนัล → ต้าอิ้ง → ฉังไจ้ → กุ้ยเหริน → ผิน → เฟย → กุ้ยเฟย → หวงกุ้ยเฟย → ฮองเฮา → ไทเฮา
 (宫女)    (答应)    (常在)    (贵人)    (嫔)   (妃)    (贵妃)     (皇贵妃)     (皇后)   (皇太后)
```

แต่ละขั้นมี **บททดสอบประจำขั้น** (เนื้อเรื่องหลัก 2–4 ตอน) และ **พิธีรับราชโองการเลื่อนขั้น** — ต้องมีทั้งเวลา ความโปรดปรานของฮ่องเต้
ศักดิ์ศรี และผ่านบททดสอบ จึงจะได้ขึ้นขั้นถัดไป ยอดสุดคือ **ไทเฮา** ซึ่งเป็นตอนจบแบบ "true ending"

## ▶️ วิธีเล่น

- **1 ตา = 1 ฤดูกาล** (เทศกาล ชมบุปผา · ตวนอู่ · จงชิว · ตรุษ) ในแต่ละฤดูมี **แต้มกิจกรรม 2 แต้ม** ใช้กับ
  ฝึกฝนตน (กวี พิณ ระบำ ตำรา ปักผ้า) · สัมพันธ์ในวัง (เดินสวนหลวง คารวะฮองเฮา ถวายพระพรไทเฮา ถวายชาฮ่องเต้ ผูกมิตร ติดสินบน)
  · อุบาย (สืบข่าว วางอุบาย ตรวจตราความปลอดภัย) แล้วจึงกด "สิ้นสุดฤดูกาล"
- ระหว่างทางจะเกิด **เหตุการณ์** (นิยายภาพ) ที่มีตัวเลือกจริง — บางตัวเลือกต้อง **ทอยด้วยสถานะ** (ขึ้นโอกาส % ให้เห็น) บางตัวเลือกต้องจ่ายเงินตำลึง
- **สถานะ:** ความโปรดปราน ♥ · ศักดิ์ศรี ♛ · ปัญญา · โฉมงาม · พรสวรรค์ · คุณธรรม · สุขภาพ · เงินตำลึง · **ภัยรอบกาย ⚠**
  (ยิ่งสูง ศัตรูยิ่งหมายหัว — ถ้าประมาท อาจถูกใส่ร้าย ถูกลดขั้น หรือถูกประหาร)
- **สายสัมพันธ์:** ฮองเฮา · ไทเฮา · เจียอี้หวงกุ้ยเฟย · เหมยชิง · ชุนเถา · ขันทีจางฝู · หมอหลวงเซี่ย · อ๋องรุ่ย (และศัตรูตัวฉกาจ ฉู่กุ้ยเหรินกับอี๋ผิน)
- เริ่มเกมเลือก **ที่มา 3 แบบ** (ธิดาขุนนางแมนจู · ธิดานักปราชญ์ฮั่น · นางกำนัลชั้นต่ำ ← ยากสุด เริ่มจากก้นบึ้งจริงๆ) และ **พรสวรรค์ติดตัว 4 แบบ**
- **ตอนจบ 27 แบบ** มีทั้งไทเฮาผู้เมตตา / ผู้สำเร็จราชการหลังม่าน / ผู้โดดเดี่ยว / ตำนานนางกำนัล และตอนจบเศร้า ตอนจบรัก และทางเลือกที่จะ "ลงจากบันได"
  สมุด **จดหมายเหตุ** เก็บตอนจบที่ปลดล็อกไว้
- ปุ่มลัด: `Space`/`Enter` เดินเรื่อง · `1–4` เลือกตัวเลือก · `A` auto · `L` ย้อนบทสนทนา · `Esc` เมนู · มีบันทึกอัตโนมัติ + 4 ช่องเซฟ

## ✨ สิ่งที่อยู่ในเกม

- **549 เหตุการณ์ · ~8,800 โหนดบทสนทนา** (ภาษาไทยทั้งหมด) แบ่งเป็น บททดสอบประจำขั้น 8 ชุด · พิธีเลื่อนขั้น 8 ฉาก · เทศกาล 24 ฉาก · ฉากสุ่มและเหตุการณ์ตามกิจกรรมนับร้อย ·
  เรื่องราวของเพื่อนร่วมทาง (เหมยชิง ชุนเถา หมอหลวง อ๋องรุ่ย จางฝู ไทเฮา) · เหตุร้ายจากศัตรู · เส้นทางล่มจม · ฟินาเล่ชิงบัลลังก์
- **ภาพทั้งหมดเป็น SVG สร้างด้วยโค้ด** (ตัวละคร 15 คน × 8 สีหน้า เครื่องแต่งกายของนางเอกเปลี่ยนตามขั้น · ฉาก 24 แบบ เปลี่ยนตามฤดู) — ไม่มีไฟล์ภาพภายนอก
- **เสียงสังเคราะห์ด้วย Web Audio** (ดนตรีสเกลห้าเสียงแบบกู่เจิง · เสียงฆ้องตอนเลื่อนขั้น)
- **ตู้เสื้อผ้า 👘** — 5 ช่อง (ชุด · เครื่องหัว · สร้อยคอ · ต่างหู · ของติดตัว) 78 ชิ้น สวมได้ตามฐานะ ลองสวมก่อนซื้อ ได้ของพระราชทานตอนเลื่อนขั้น ซื้อด้วยเงินตำลึง และได้เป็นของขวัญจากฮ่องเต้/ไทเฮา/ฮองเฮา/เหมยชิง · มีผลต่อการทอยเต๋า ศักดิ์ศรี และภัยรอบกาย · สวมโทนเดียวกันครบได้โบนัสชุดเซ็ต · ภาพนางเอกเปลี่ยนตามชิ้นที่สวมจริง
- **พระนามและฉายา 🪪** — การเรียกขานสนมสมจริงตามธรรมเนียมวังชิง: ต่ำกว่าผินเรียก **สกุล + ยศ** (เช่น "เซิ่น ฉังไจ้") · เลื่อนเป็นผินแล้วฮ่องเต้พระราชทาน **ฉายา (封号)** เป็นอักษรจีนหนึ่งคำ แล้วเรียก **ฉายา + ยศ** ("ลิ่งผิน" → "ลิ่งเฟย") · ถ้าทรงโปรดปรานมากอาจประทานฉายาก่อนถึงผิน · ตั้งแต่หวงกุ้ยเฟยจะได้ **อักษรเพิ่มอีกหนึ่งคำ** ต่อท้ายหรือนำหน้า ("ลิ่งอี้หวงกุ้ยเฟย") · ถูกลดขั้นหรือตกต่ำจากพระเนตรนานอาจถูก **ริบฉายา** แล้วตั้งใหม่ภายหลัง · ฉายามาจากคลังอักษรมงคลหลายร้อยคำพร้อมความหมายและที่มา เลือกตามคุณสมบัติของท่าน (ถ้าทรงโปรดปราน ได้เลือกเองจากสามคำ) · ผู้เล่นนางกำนัลตั้งแซ่เองได้ · สนมหน้าใหม่ (ซิ่วหนี่) ก็ได้ฉายาเมื่อเป็นผิน · มีหน้า "พระนาม" (พระนามปัจจุบัน ทำเนียบการเรียกขานแต่ละยศ ประวัติฉายา) และพิธีประกาศฉายาแบบราชโองการ
- **พลิกป้าย 🎴** — ตั้งแต่ขั้นฉังไจ้ ท่านมีป้ายชื่อเขียวของตนเอง ทุกสิ้นฤดูฮ่องเต้ทรงพลิกป้าย 1–3 ใบจากท่าน สนมในวัง และซิ่วหนี่รุ่นใหม่ โดยน้ำหนักขึ้นกับความโปรดปราน ฐานันดร โฉมงาม พรสวรรค์ ขันทีจางฝู เครื่องแต่งกาย และ "อารมณ์ฮ่องเต้" ที่แกว่งทุกฤดู · ฝากขันทีจัดคิวด้วยเงินตำลึง · ฮองเฮา/ไทเฮาที่ไม่พอใจขีดชื่อท่านได้ · ถ้าป้ายถูกพลิกจะมีฉากค่ำคืนในฤดูถัดไป (ปิดฉากแบบนุ่มนวล ไม่แตะเรื่องมีทายาท) · ฮองเฮาไม่มีป้าย ฮ่องเต้เสด็จตามวาระ · มีหน้าป้ายชื่อเขียว (คิวป้ายพร้อมเปอร์เซ็นต์ ปัจจัย และประวัติ)
- **ซิ่วหนี่ 📜** — ทุก 3 ปีมีรุ่นสนมใหม่ 2–3 คนเข้าวัง (สร้างแบบสุ่ม: ชื่อ ตระกูล ภูมิหลัง นิสัย 6 แบบ ความทะเยอทะยานและสายสืบที่ซ่อนอยู่ พร้อมภาพตัวละครของตัวเอง) ขั้นเฟยขึ้นไปร่วมพิจารณาได้: สืบประวัติ → รับเข้าสังกัด / ปล่อยตามชะตา / ส่งเป็นนางกำนัลข้างกาย / คัดออก · สนมในสังกัดช่วยกราบทูลและเป็นหูเป็นตา แต่บางคนทะเยอทะยานจนหักหลัง บางคนเป็นสายสืบมาตั้งแต่แรก ตระกูลใหญ่ที่ถูกคัดออกก็แก้แค้นได้ · มีหน้ารายชื่อ (รอพิจารณา/สังกัด/ในวัง/จากไป) และเหตุการณ์เรื่องราว 12 ฉากที่อ้างถึงสนมคนนั้นด้วยชื่อ
- ระบบ **ลำดับขั้น (Ladder)** ที่แสดงความคืบหน้าไปขั้นถัดไปตลอดเวลา · พิธีรับราชโองการเลื่อนขั้น · จดหมายเหตุ · ย้อนบทสนทนา · auto/skip

## 🗂️ โครงสร้างโปรเจกต์

```
index.html · css/style.css · js/engine.js     UI (ครอบบน logic.js — ไม่มีกฎเกม)
js/core_data.js                               ตารางกลาง: สถานะ ลำดับขั้น เกณฑ์เลื่อนขั้น ที่มา กิจกรรม ตัวละคร ฉาก
js/logic.js                                   ตรรกะล้วน (ไม่มี DOM) — ใช้ทั้งในเบราว์เซอร์และ Node: ฤดูกาล เหตุการณ์ ตัวเลือก ทอยเต๋า ตอนจบ
js/art_chars.js · js/art_bg.js · js/sound.js  ภาพตัวละคร / ภาพฉาก / เสียง (สร้างด้วยโค้ด)
js/data/*.js                                  เนื้อเรื่องทั้งหมด (Q.add([...]))
docs/BIBLE.md · docs/DESIGN.md                คัมภีร์เรื่อง (ตัวละคร พล็อต ธง) และสัญญาทางเทคนิค (schema เหตุการณ์)
tools/validate.js                             ตรวจโครงสร้างเนื้อเรื่อง + เดินสุ่มทุกฉาก
tools/bot.js                                  บอทจำลองเล่นหลายร้อยรอบ วัดบาลานซ์/จุดติด/ตอนจบที่เข้าถึง
tools/uitest.js                               ทดสอบ UI ด้วย Playwright (คอม+มือถือ) พร้อมภาพหน้าจอ
tools/sync_index.js · build.js                ซิงก์รายการสคริปต์ / รวมเป็น standalone.html
```

## 🛠️ สำหรับนักพัฒนา

```bash
node tools/validate.js --all          # ตรวจเนื้อเรื่องทั้งเกม (ต้องไม่มี ERROR)
node tools/bot.js --runs=300 --policy=smart --stats      # จำลองเล่น (policy: smart|gentle|ruthless|reckless|random)
node tools/sync_index.js --exclude=00_sample.js && node build.js   # สร้าง standalone.html
node tools/uitest.js --device both    # ทดสอบ UI (ต้องมี playwright)
node tools/wardrobetest.js            # ทดสอบหน้าตู้เสื้อผ้า
node tools/xiunutest.js               # ทดสอบระบบซิ่วหนี่ (รุ่นเข้าวัง/พิจารณา/แท็บ/ฉากเรื่อง)
node tools/tablettest.js              # ทดสอบหน้าป้ายชื่อเขียว (คิว/ฝากขันที/ประวัติ/โหมดฮองเฮา)
node tools/namingtest.js              # ทดสอบหน้าพระนาม (ช่องแซ่/ฉายา/พิธี/อักษรเพิ่ม/ริบ-ตั้งใหม่)
node tools/nmcheck.js                 # ตรวจกติกาการเรียกขานแบบไม่มีหน้าจอ (หลายร้อยฤดู)
node tools/namelint.js                # ตรวจคลังฉายา/สกุล/ชื่อสตรี (js/data/n0*.js)
```

เพิ่มเนื้อเรื่อง: สร้าง `js/data/cNN_*.js` แล้วเรียก `Q.add([{ id, kind, title, minRank, maxRank, bg, cast, start, nodes }])`
(รูปแบบเต็มดู `docs/DESIGN.md`; ตัวอย่าง `js/data/00_sample.js`) จากนั้นรัน `validate.js` และ `sync_index.js`

> ผลจำลองด้วยบอท (300 รอบ): บอทที่รู้ผลทุกตัวเลือกไต่ถึงไทเฮาราว 89% บอทสุ่มราว 3% — ผู้เล่นจริงที่ไม่เห็นตัวเลขจะยากกว่านี้มาก
> ค่าสมดุลทั้งหมด (อัตราลดความโปรดปราน เกณฑ์เลื่อนขั้น ตัวคูณศักดิ์ศรี ความถี่เหตุร้าย) อยู่ใน `Q.CONST` / `Q.GATES` ใน `js/core_data.js`
